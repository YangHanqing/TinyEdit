# Markdown 预览验证示例

`compatibility.md` 覆盖标题、列表与引用嵌套、围栏代码、表格对齐、待办、删除线、链接、图片、`img` 整数尺寸和 `br` 换行；包含缺失图片和需要手动加载的远程图片。图片路径指向仓库已有截图。

`navigation.md` 用于检查长文档中尚未进入屏幕的嵌套标题及百分号编码锚点。

在 TinyEdit 打开示例，按 ⇧⌘V 显示预览。预览支持选中文本，链接可按住 ⌘ 点击。将窗口收窄，检查表格自身横向滚动、图片缩放和长文本换行。遇到本地图片授权提示，选择 `assets/screenshots`；切换标签页、关闭后重开或退出后重启，检查图片是否恢复。

远程示例指向 `localhost:18474/remote.png`。没有启动本机服务时，点击加载会显示失败提示，可手动重试；显示预览本身不会发起此请求。

当前边界：

- 解析依赖 Foundation，覆盖已验证的日常 CommonMark/GFM 用法，没有执行完整规范一致性测试。空替代文字的图片链接（`[![](图片)](链接)`）仍可能被 Foundation 丢弃；请为其填写替代文字。
- HTML 仅解释 `img` 和 `br` 子集，其他 HTML 显示源码；不执行 HTML、CSS 或 JavaScript。
- 图片作为独立块排列，不提供浏览器式图文环绕。HTML 尺寸仅支持正整数边界，保留图片比例；图片解码最大边长 1600，文件最大 64 MB。
- 仅支持本文标题片段跳转。标题按小写、移除标点、空白变连字符生成片段，重复标题加 `-1`、`-2`；支持中文、百分号编码及 Unicode 规范化。不提供跨文件片段跳转和自定义 HTML 锚点。
- 代码高亮复用编辑器扫描器；未知语言和超过 2 MB 的单个代码块保留纯文本。复制不包含围栏和语言标签，保留代码正文缩进与换行。
- 超过 5 MB 的文档继续停用预览。没有增加数学公式、Mermaid、脚注或双向链接。
